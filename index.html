Solutions We Tried

Vite

  • Much faster than Webpack
  • Excellent Dev Server
  • Very fast HMR
  • Great developer experience

But: We faced stability issues with some libraries in the large project

Rsbuild (What we adopted)

  • Built on Rust - Native speed
  • Very high performance - Fastest of all
  • Stable on large project - 100% reliable
  • Simpler configuration - Easy setup
  • Suitable for Enterprise CRM - Designed for large projects
